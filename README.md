One original fortune-cookie line for a software developer: "Your future self is already debugging the shortcut you are about to take." It opens like a fortune, it is true about every developer's day — shortcuts, and the debugging that follows them — and its twist is the tense: the debugging has already begun for a shortcut not yet taken.

`main.ts` writes that single line (73 characters, no trailing newline) to `/output/entry.txt`, failing loudly if the line ever exceeds the gate's 120 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
